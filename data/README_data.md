# data/

Place your labelled resume CSV files here.

## Expected format

```csv
resume,label
"Full resume text here...","Data Scientist"
"Another resume...","Software Engineer"
```

### Recommended datasets

- [Kaggle — Resume Dataset](https://www.kaggle.com/datasets/gauravduttakiit/resume-dataset)
- [GitHub — ResumeParser datasets](https://github.com/florex/resume_corpus)

Minimum recommended: **500+ samples** across your target categories for reliable fine-tuning.
